# AnyRecord Branding & Media

This directory is the single source of truth for all AnyRecord branding, icons, and showcase media assets.

## Directory Structure

- **`logo/`**: Official master vector (`.svg`) and high-resolution master raster files (`.png`).
  - `AnyRecord.svg`: Primary vector logo.
  - `anyrecord-generic.svg`: Monochrome/generic icon vector.
  - `anyrecord-1024.png`: 1024x1024 high-resolution master asset.
- **`icons/`**: Multi-resolution platform icons for Windows, macOS, and Linux.
  - `icon.ico`: Windows icon with embedded multi-size alpha layers.
  - `icon.icns`: macOS icon bundle.
  - `icon-{16..1024}.png`: Sized PNG icons for system tray, taskbar, dock, and web.
- **`media/`**: Official product demo animations, GIFs, and screenshots.
  - `demo.gif`: Main product overview demo.
  - `CursorLoop.gif` & `CursorSwayDemo.gif`: Cursor physics & smoothing showcase.
  - `feature1.gif`, `feature2.gif`, `feature3.png`: Feature spotlights for editor, zoom, and canvas framing.
